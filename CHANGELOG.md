# Changelog

## Unreleased

## [0.4.0](https://github.com/sparr/messagefromaliens-mod-CompoundTranslations/releases/tag/v0.4.0) - 2026-11-22

- A compound's parts can be labeled and edited by their position translations, and hints include the compound's word type.
- Brackets default to `[]`.
- Sequence translations no longer form across empty cells, lists, conjunctions, or settings page choices.
- Tab moves through position fields and run labels, following Interface Tweaks' order.
- `?` counts as no translation.
- The positions panel offers every position a glyph takes in the game's compounds, seen or not.
- Fixed run label editing, the positions panel, and labels while translations are hidden.
- Faster hint updates.

## [0.3.1](https://github.com/sparr/messagefromaliens-mod-CompoundTranslations/releases/tag/v0.3.1) - 2026-11-17

- Fixed the position translations button after the game's 2026-11-16 update.

## [0.3.0](https://github.com/sparr/messagefromaliens-mod-CompoundTranslations/releases/tag/v0.3.0) - 2026-11-15

## [0.2.0](https://github.com/sparr/messagefromaliens-mod-CompoundTranslations/releases/tag/v0.2.0) - 2026-11-15
